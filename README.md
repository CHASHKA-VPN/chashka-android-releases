# ЧАШКА КОФЕ | VPN для Android — сборки

Здесь только готовые сборки приложения для Android и лента обновлений. Кода здесь нет.

**Установить.** Скачайте из [последнего выпуска](../../releases/latest) APK для своего телефона — почти всегда `ChashkaKofe-<версия>-<номер>-arm64-v8a.apk`, а `armeabi-v7a` — только для старых телефонов — и откройте его. Android один раз попросит разрешить установку из этого источника.

**Обновления приходят в приложении.** Оно раз в несколько часов сверяется с лентой `feed.json` последнего выпуска, само скачивает новую версию по Wi‑Fi и предлагает обновить.

**Подмена не пройдёт.** APK и лента подписаны одним ключом: поверх установленного Android не поставит APK с другой подписью, а приложение не примет ленту, подписанную чужим ключом. Суммы SHA-256 файлов — в `SHA256SUMS` каждого выпуска.
